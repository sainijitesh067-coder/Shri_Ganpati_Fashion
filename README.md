# Shri Ganpati Fashion 👗

Welcome to **Shri Ganpati Fashion** — a modern and attractive fashion website created to showcase different dresses and fashion collections.

## 🌐 Live Website

[Visit Shri Ganpati Fashion](https://sainijitesh067-coder.github.io/Shri_Ganpati_Fashion/)

## 📌 About The Project

**Shri Ganpati Fashion** is a fashion website designed to display clothing collections in a simple and user-friendly way.

The main purpose of this project is to create an attractive online fashion platform where users can explore different dresses and fashion designs.

## ✨ Features

* 🏠 Attractive Home Page
* 👗 Fashion & Dress Collection
* 🖼️ Product/Dress Images
* 📱 Responsive Website Design
* 🎨 Simple and Modern UI
* 🔗 Easy Navigation
* 💻 User-Friendly Interface

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and layout
* **JavaScript** – Website functionality
* **GitHub Pages** – Website hosting

## 🚀 How To Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser.
4. Explore the Shri Ganpati Fashion website.

## 🎯 Project Objective

The objective of this project is to develop a simple and attractive fashion website that provides users with an easy way to view different clothing designs and collections online.
